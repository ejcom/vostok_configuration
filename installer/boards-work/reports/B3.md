## fly-super8-pro-h723

| Поле | Значение | Источник | Уверенность |
|---|---|---|---|
| CHIP | stm32h723xx | M-PRO-KL (Processor model STM32H723), общая страница: STM32H723ZGT6 и упоминание версии на H743 | средняя: схема в репозитории показывает STM32H743ZIT6 |
| CLOCK | 25M | M-PRO-KL, M-PRO-KT (25 MHz crystal) | низкая: M-PRO-SCH показывает кварц 8MHZ (JZ1) |
| APP_OFFSET | 20000 | M-PRO-KL, M-PRO-KT (128KiB bootloader SKR SE BX v2.0, 128KiB offset) | средняя: один источник (Mellow), схема об offset молчит |
| USB | PA11_PA12 | M-PRO-KL/KT; M-PRO-SCH (OTG_FS PA11/PA12 на Type-C) | высокая |
| CAN | PB8_PB9 | M-PRO-KL (CAN bus on PB8/PB9); M-PRO-SCH (PB8/PB9 -> CAN TX/RX -> MCP2542) | высокая |
| CAN bridge | есть | M-PRO-KL (USB to CAN bridge) | высокая |
| DFU | джампер BOOT0 + USB | M-PRO-BL ("install the jumpers ... before plugging in USB"); схема: узел BOOT0 с джампером | средняя: расположение джампера только на рисунке |
| DFU_HOW | jumper | как выше | средняя |

Не подтверждено: кварц (25 против 8 МГц) и чип (H723 против H743) - два источника расходятся. Схема в репозитории может быть от более ранней ревизии (2022-09-06), но подтвердить нечем. Пользователь обязан проверить маркировку до прошивки (записано в NOTE).

## mks-skipr

| Поле | Значение | Источник | Уверенность |
|---|---|---|---|
| CHIP | stm32f407xx | MKS-SK-SCH (U17 STM32F407VET6), README MKS-SKIPR | высокая |
| CLOCK | 8M | MKS-SK-SCH (Y4 8M) | высокая |
| APP_OFFSET | 8000 | не подтверждено документацией: стоковая сборка MKS - 48KiB, SD-прошивка mks_skipr.bin (MKS-SK-CFG); установщик ставит katapult 32KiB | низкая |
| USB | PA11_PA12 | MKS-SK-SCH (USB_D-/D+ на PA11/PA12, к Type-C) | высокая, но хост по USB не подключён |
| CAN | "" | схема: CAN2 на PB12/PB13 (pins 51/52), трансивер на плате (лист 28); форум SKIPR CAN Bus - тот же CAN2. Но связь MCU с SoC RK3328 только UART1 (MKS-SK-CFG), USB-моста к хосту нет | CAN-пины высокая; моста нет -> CAN пустой |
| DFU | кнопки BOOT0 (S2) + RESET (S1) по схеме | схема (листы 21); документации MKS на DFU нет | низкая |

Не подтверждено: DFU и offset. Нештатный режим: штатная связь UART; USB-сборки katapult подходят только при подключении Type-C к хосту. Это записано в DFU_HINT и NOTE. Если интегратор сочтёт плату не подходящей установщику (он строит USB-прошивки), её можно убрать: остальные платы от неё не зависят.
